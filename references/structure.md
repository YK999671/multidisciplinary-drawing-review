# 结构检查包 STR

## 输入与关系

结构总说明、基础与各层布置、构件表、配筋/连接详图、设计变更；按检查需要读取地勘、荷载条件和计算书。建立构件—明确支承/连接—构件关系，不能用投影重叠证明支承。

| 规则族 | 检查动作及证据 |
|---|---|
| STR-01 基线 | 体系、材料等级、设计参数和分区在说明、表格、详图、变更间一致；只核实表达不代替设计选型 |
| STR-02 定位 | 基础、柱墙梁板和洞口按轴网/标高逐层对应，特殊层、变截和转换部位单列 |
| STR-03 构件身份 | 构件编号、截面、材料、配筋表达与表/详图双向索引；相同编号不同实例不混淆 |
| STR-04 连接与连续 | 支承、连接、锚固/搭接及节点适用范围有明确表达；上/下层构件变化能追踪到处理说明 |
| STR-05 基础与地下 | 基础布置、承台/地梁、坑槽、地下外墙、底板、施工缝/后浇带及防水接口在平剖节点间对应 |
| STR-06 开洞与埋件 | 建筑洞口和机电留洞对应结构批准表达，尺寸/标高/边距/加强措施及预埋条件闭合；不自行建议切断钢筋 |
| STR-07 荷载接口 | 设备、屋面设施、幕墙、吊挂、重饰面等提供的重量、支点和作用条件与结构采用条件对应；无输入则待确认 |
| STR-08 可施工性 | 节点层次、构件交汇、钢筋/连接件空间和施工顺序有依据；二维密集线只作候选，不直接认定无法施工 |

对图面明确的数量/尺寸/参数矛盾可提出确认问题；承载力、抗震、稳定、挠度及基础设计安全必须进入独立计算复核，不因“看起来连续”判定满足。

输出构件及节点对照、层间变化、荷载/开洞接口、计算书输入不一致和需专业复核项。未经地勘与设计输入核实，不对基础选型作确定性否定。

## 基础、坑槽和节点的实质核对

- 把零点换算、默认顶标高、局部降/抬板、坑底、构件厚度及底标高分列。先读默认值的例外条件；若说明要求跨不同板面按最低板面，应先确认该实例覆盖的板区，不能把默认顶标高机械套到坑部再减厚度。
- 平面与详图分别采用相对/绝对标高时，先核零点、对象与各自适用范围。能换算不等于位置已对应；措辞不同也不自动构成数值矛盾。未知的局部板面不能用符号节点几何Z或线长填补。
- 按“平面实例—编号及引线—表列一般参数—局部覆盖标注—剖切索引—对应节点”核对。一般厚度与表一致不包含填充范围局部加厚；一般说明、节点例外分别记录。
- 节点注明的不等式或构造尺寸，可在适用对象及输入明确后复算；记录所用图示尺寸、参数和结果。节点回指存在只达到索引核对，不证明全部尺寸、配筋、锚固或施工高程通过。
- 数量、一般厚度、局部节点尺寸、逐桩定位、墙柱支承及插筋分别记录完成边界。部分子项通过时，原有综合基础检查仍保留尚未完成的内容。

涉及尺寸覆盖、镜像及数量去重时，使用[CAD证据核验](cad-evidence-verification.md)。
