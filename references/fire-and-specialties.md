# 消防专题与专项路由

## 消防 FIRE：跨专业一致性专题

从正式设计条件/说明识别建筑用途、分区和系统范围；条款阈值需核实适用版本。读取建筑、结构、给排水、暖通、电气、智能化及精装中的相关部分，不能把消防当作一张末端点位图。

| 规则族 | 跨专业检查链 |
|---|---|
| FIRE-01 分区 | 建筑分区边界、门/墙/楼板表达，与穿越管线、阀件、封堵和控制分区对应；图面边界变化须追踪 |
| FIRE-02 通行 | 空间—门—走道—楼梯—出口/室外逐段确认，检查标高、门五金、门禁、装修及设备占用；不以单层图证明整栋路径 |
| FIRE-03 消防水 | 水源/设备—供水分区—管网—末端，连接水专业与建筑空间、供电/控制条件 |
| FIRE-04 防排烟 | 服务区域—送/排/补风系统—阀件—风机—室外端与分区、建筑开口和电气控制对应 |
| FIRE-05 报警联动 | 触发输入—逻辑/模式—控制输出—执行设备—反馈闭环，逐项关联点表、原理及设备专业 |
| FIRE-06 供电应急 | 对应系统的电源、线路、切换、终端及应急设备控制表达一致；可靠性满足需另核实依据 |
| FIRE-07 构造接口 | 门窗/围护性能表达、穿越封堵、机电安装及精装材料要求与相关节点/说明一致 |

先查表达和关系闭合，再查已核实规范。区域、人数、用途或计算资料不足时，保留高影响待确认，不降低严重度、不认定满足或不满足法定要求。

## 其他专项 SPECIAL

建立适用性清单：总平/室外管网、幕墙、景观、燃气、人防、电梯、厨房/医疗/洁净/工艺、节能、声学、防水等，仅启用项目实际需要的内容。此列表不是缺失判定依据。

当前没有完整独立检查包的专项，最低先做目录/说明/版本、对象与系统、输入输出条件、跨专业接口和证据登记。基于实际专项说明及正式资料建立项目规则；缺少专业依据时标记检查包缺口和所需人员/资料，不借用相似专业规则声称审查完成。

每个专项的入口检查：

- 幕墙：分格/支承、主体连接、预埋、变形、收口、防水及机电穿越。
- 电梯：井道/底坑/顶层、结构支承、门洞、供电控制、运输安装与检修条件。
- 室外：单体出入户点、管网标高、道路/地形、基础及市政边界。
- 燃气、人防、工艺等：先查设计条件和系统边界，再建立有依据的专项规则；专业参数和合规结论不得猜测。

专项输出必须区分“接口已查”和“专项内部检查已完成”，两个状态不能互相替代。
