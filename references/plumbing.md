# 给排水检查包 PLB

## 输入与追踪

说明、图例、平面、系统/轴测图、机房详图、设备表、室外管网及接驳条件。按用途和分区分别建系统，不把生活给水、热水回水、污废水、雨水、冷凝排水、消防水等同名管段混接。

| 规则族 | 检查动作及证据 |
|---|---|
| PLB-01 身份 | 系统、分区、立管号、设备号在平面/系统/表格一致；立管跨层和出户位置可追踪 |
| PLB-02 上下游 | 从供水源/设备到干支管及末端，从排水器具到支立管、出户及室外受纳点逐支追踪；交叉线不自动接通 |
| PLB-03 参数 | 管径、材质、压力表达、坡度、流向、标高及设备参数跨图互核；系统示意线长不能作实际长度 |
| PLB-04 分区与回路 | 分区边界、增压/减压、回水、旁通和隔断按图示关系闭合；缺阀件先查说明及系统详图 |
| PLB-05 排水高程 | 区分管底/中心、内底/外底、坡向和长度依据；沿路径核对高程链、穿梁/基础、接驳点，数据不足不称重力流可行 |
| PLB-06 机房设备 | 设备表、平面、基础、接口、阀组、排水、吊装和拆换空间对应；泵参数一致不证明水力设计满足 |
| PLB-07 运维与施工 | 隔断、清扫/检查、检修、放空/泄水、套管、防水封堵的表达及操作空间；不得只查末端 |
| PLB-08 边界 | 市政接驳条件、压力/标高、排放去向、供货/安装/调试边界明确，室内外编号可对应 |

室外资料缺失时保留该端点为未知，不能把室内系统图画到出户即认定全链闭合。水量、水压、水力平衡、泵选型和储水容量的满足性需要独立输入与复算。

输出按系统/分区的源—干线—分支—末端追踪表、参数差异、未知接点、接驳与机房接口。消防水系统同时纳入消防专题。

## 立管及出户编号追踪

逐组核上下端编号、连续线、接点及跨图标记，避免把相邻系统组的标签拼接为同一管路。保留原文；统一字符写法只供检索，不能消除原图中的实质编号差异。搜索不到某立管号不等于缺管，须继续查缩写、成组标注、其他图框及读取限制。同一支路上下端编号不一致时，仅判编号表达问题；排水能力、现场接错或漏管须另有证据。
