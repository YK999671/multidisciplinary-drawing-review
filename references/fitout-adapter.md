# 原精装 skill 接入

精装仍由独立的 `interior-fitout-drawing-review` skill 执行专业内部检查，不在本仓库复制或修改其文件。使用时先从当前环境的技能目录查找并读取其 `SKILL.md`；找不到时明确精装包不可用，继续其他专业，不宣称精装已完成。

读取原 skill 的 references/interior-fitout-checks.md；涉及机电、标准、招标界面时再读取相应参考文件。沿用空间跨图、材料、节点、门、天花、家具、操作/检修、加工和施工顺序规则。

## 接入约定

- 上游接收主 skill 的有效图面、项目规则、空间/系统 ID、坐标标高基准和检查计划；原 skill 的房间模型作为局部模型，不替代主 skill 的全楼/系统模型。
- 规则映射为 FITOUT-原规则族-序号，保留原出处；规则未细分编号时实际审查中分配稳定 ID。
- 原楼栋/层型/户型/房间映射到 scopes，并保留每个实际实例；原图号、句柄、文字、截图映射为 evidence。
- 原“高/中/低”映射为 high/medium/low；问题类型保持语义，规范不符合使用主 skill 的 verified_noncompliance。
- 原 covered/checked 类结果不能直接视为通过；补齐 rule_id、目标/实际深度、有效证据和 review_status。
- 精装与机电末端问题同时关联对应系统或接口范围。与其他专业重复发现时合并根因，保留各实例和双向专业引用。
- 主 skill 统一覆盖分母、证据独立性、严重度/确定性分离和闭环校验；原 skill 的局部模板/脚本不能覆盖这些总控字段。

原脚本可作为辅助，但其校验通过不代替 validate_review.py 和图面复核。接入不代表精装包已经补齐全专业系统审查，也不使其他专业自动完成。
