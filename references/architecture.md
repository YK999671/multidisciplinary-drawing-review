# 建筑检查包 ARC

## 输入与关系

总平、说明、各实际楼层平面、屋面、立剖面、门窗表、构造及索引详图；按项目补充功能/防火/无障碍/节能专题。建立场地—出入口—单体—楼层—空间—门/通道关系，与轴网、标高和围护构造关联。

## 最低检查路径

| 规则族 | 检查动作及证据 |
|---|---|
| ARC-01 范围 | 目录对图框，逐层核对地下、首层、转换/避难/设备等特殊层、屋面与标准层适用范围；缺图要有预期依据 |
| ARC-02 定位 | 总平定位、单体轴网、平立剖标高和层高对应；核对相对/绝对基准及室内外高差，不能直接混用 |
| ARC-03 空间 | 房间用途、边界、门窗洞口、竖井在平立剖和表格间对应；同名空间按实例区分 |
| ARC-04 路径 | 逐步证明入口、走道、楼梯、出口的实际连接和高差；净宽、净高、门开启及障碍结合图面，不能只连房间文字点 |
| ARC-05 围护 | 墙、屋面、门窗、幕墙接口的构造层次、厚度、完成面及节点索引；材料表与说明互核 |
| ARC-06 水与高差 | 屋面/阳台/湿区排水方向、坡度表达、落水点、门槛/反坎、溢流及防水收头在相关图中能否执行 |
| ARC-07 垂直空间 | 楼梯平台、梯段、井道、检修口、设备运输通道用平剖面闭合；标高不等于净高 |
| ARC-08 施工表达 | 总分尺寸、轴线定位、洞口、变形缝、详图索引是否足以放样；“现场定”对应责任与冻结条件 |

## 接口与边界

与结构核对轴网、梁柱墙板、洞口、结构与建筑标高；与机电核对机房/竖井、洞口、设备运输、屋面设备及排水；与精装核对完成面和功能尺寸。消防路径交给消防专题串联，不能仅因一层疏散图完整即判整栋满足。

距离、面积、数量及性能限值从适用项目依据取得。检查图纸自洽与核实条款分开；没有人员/用途/高度等适用条件不确认规范符合。

输出空间跨图记录、路径证据链、建筑与结构标高对照、构造/索引缺口及接口问题。
