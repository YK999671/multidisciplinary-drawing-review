# 智能化检查包 ICT

## 输入与追踪

系统说明、系统图、平面、点表、设备表、网络/机房及供电条件、接口协议和控制说明。按通信、综合布线、安防、门禁、楼控等实际系统分别建模，不按“弱电”一项整体打勾。

| 规则族 | 检查动作及证据 |
|---|---|
| ICT-01 链路 | 平台/主机—网络/控制器—传输链路—终端逐级追踪，系统图和平面编号对应 |
| ICT-02 点表 | 点位数量、设备号、输入/输出类型、信号来源、执行对象及状态反馈在点表/控制说明/专业图一致 |
| ICT-03 条件 | 设备供电、通信介质、机柜/端口、散热、安装及检修条件有明确来源；不从图标外形推定型号能力 |
| ICT-04 功能 | 门禁/安防与门五金、空间用途、建筑通行及消防联动条件相互协调，不能仅确认安装位置 |
| ICT-05 接口 | 通信协议、信号形式、软硬件边界、调试和交付责任明确；无合同仅标建议归口 |
| ICT-06 物理路径 | 桥架、竖井、管路、预埋、穿墙封堵与电气/机电/精装对应；逻辑联网不证明路由可施工 |

网络容量、无线覆盖、安防有效性及控制性能需要相应参数和验证，不能凭图纸点位齐全确认。未经提供的设备规格书，不假设协议或接口兼容。

输出端到端链路、点表差异、跨专业信号/责任边界、安装与调试缺口。
