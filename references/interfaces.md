# 跨专业接口检查包 IF

以接口对象为中心记录：提供方条件、接收方采用值、双方有效图号、位置/坐标/标高基准、冻结状态、判定规则和证据。没有正式责任资料时仅给建议归口。

| 规则族/接口 | 必须对照的两端及检查 |
|---|---|
| IF-01 建筑—结构 | 轴网、构件、层高/标高、洞口、楼梯、坑槽、变形缝；区分结构与完成面 |
| IF-02 结构—机电 | 设备基础/荷载、孔洞套管、预埋件、支吊架条件；设备侧要求与结构接受条件一致 |
| IF-03 建筑—机电 | 机房/竖井/门洞尺寸、进排风开口、运输路径、防水及出入户标高 |
| IF-04 机电—机电 | 设备用电、冷热源、补排水、控制信号与各专业表格/系统对应；系统边界不以平面相邻替代 |
| IF-05 综合空间 | 梁板、风管、水管、桥架、保温支架、吊顶及检修包络；同一坐标/标高基准才做真实干涉判断 |
| IF-06 精装—主体/机电 | 完成面、门柜、末端、检修、设备拆换、洞口收边和防水；回接原精装检查包 |
| IF-07 围护/幕墙—主体 | 支承/预埋、变形、外窗与洞口、保温防水收口、百叶和穿墙接口 |
| IF-08 室内—室外 | 出入户点编号、标高、压力/流向、接驳条件、地形与基础边界 |
| IF-09 消防—各专业 | 分区、通行、供水、防排烟、报警/控制、供电与封堵；读取消防专题 |
| IF-10 施工运维 | 预留→安装→封闭的工序依赖、设备进场/更换路径、可拆范围、调试检测和责任冻结 |

跨图配准先确认图面身份、轴网、单位、变换和残差；详图比例、镜像、底图版本不同不能直接叠合。空间重叠、净距疑点、确认碰撞分开；平面不相交也不证明无安装/维修干涉。

参数差异需核对语义：额定/计算/安装值、结构/完成面、管底/中心、含/不含保温等。同一数值不同基准不能直接判一致，数值不同有明确换算也不自动判矛盾。

没有合同/界面表时只列未闭合接口，不认定最终责任或清单漏项。系统图、说明、厂家条件循环互指且没有冻结值时，列出缺失决策及受影响对象。

输出接口矩阵：interface_id、双方专业/对象、输入/采用值与单位、依据、冻结状态、判断、关联 checks/issues。每个主要接口有检查记录，不只汇总已发现的问题。
