# 暖通检查包 HVAC

## 输入与追踪

说明、图例、平面、风/水系统图、设备表、机房与安装详图、控制说明；防排烟纳入消防专题。分别建立风侧、水侧、冷媒、冷凝水与控制关系，不用同一条拓扑代替全部系统。

| 规则族 | 检查动作及证据 |
|---|---|
| HVAC-01 系统归属 | 设备号、系统号、服务区域、风口/末端及立管在平面、系统图和表格对应 |
| HVAC-02 风侧闭合 | 室外取/排风端—机组—干支管—末端，送回排补风分开追踪；竖井、百叶及建筑开口有对应 |
| HVAC-03 水/冷媒侧 | 源端—输配—分支—末端—回路，核对图示流向、分区、阀组及排气/泄水表达；不能仅凭并行线断言供回水 |
| HVAC-04 参数 | 风水量、管/风管尺寸、保温、标高、设备容量及表格汇总互核；算术平衡与设计充足性分开 |
| HVAC-05 冷凝水 | 排水点、坡向、标高、存水/提升条件、出路和检修有据，跨专业接驳可追踪 |
| HVAC-06 空间 | 梁底—风管/水管/保温—支吊架—吊顶及维修包络；统一坐标与标高后才确认净空问题 |
| HVAC-07 安装运维 | 过滤器、盘管、阀件、风机/机组拆装方向、吊装运输、基础减振及检修口不被结构/精装阻挡 |
| HVAC-08 控制 | 传感器—控制器—执行器—设备—状态反馈与电气/智能化点表对应；模式和联锁按正式控制说明核对 |

防排烟、事故排风、特殊工艺等按适用性建立专项规则，不把普通通风规则直接当作完整依据。负荷、阻力、风压、噪声和热湿处理等需要完整输入与独立方法。

输出系统追踪、参数与控制点对照、净空/检修问题、室外进排风接口及缺少计算输入事项。
