# 电气检查包 ELE

## 输入与追踪

说明、供配电系统图、平面、箱柜/回路表、负荷或设备表、控制原理、照明、防雷接地和安装详图。分别记录电气连接、敷设路径和控制关系；线路交叉不证明电气连接。

| 规则族 | 检查动作及证据 |
|---|---|
| ELE-01 电源链 | 电源—变配电/切换装置—配电柜箱—回路—终端设备逐级对应，正常/备用等系统身份保持清楚 |
| ELE-02 编号与边界 | 箱柜号、回路号、设备号、服务范围、跨楼层馈线和外部接入在系统/平面/表格一致 |
| ELE-03 参数表达 | 电压、相别、容量、保护器件、线缆及敷设方式跨图对应；设备电气条件与用电专业表一致 |
| ELE-04 配电空间 | 柜箱尺寸、门开启、操作维护、运输路径、电缆进出、竖井和结构洞口条件闭合 |
| ELE-05 照明与末端 | 灯具/开关/插座回路归属、控制关系、安装定位和天花对应；不能只看末端位置 |
| ELE-06 保护接地 | 图示接地、等电位、防雷和设备连接关系在说明/详图/平面闭合，材料和引出位置可对应 |
| ELE-07 控制接口 | 设备启停、反馈、联锁和消防接口的供电/控制职责明确，不能因预留一根管认定接口完成 |
| ELE-08 施工 | 桥架/管线层位、穿越、封堵、预留和检修有定位；与给排水、暖通及结构接口复核 |

图上器件/线缆参数相同不证明选型、短路保护配合、载流量、电压降或供电可靠性满足。该类结论需项目条件、计算及适用依据；只检查到表达时如实说明。

消防供电、应急照明及相关控制交消防专题联查。输出供电链/回路对照、设备条件差异、控制与接地关系缺口、空间和计算待复核项。

## 设备身份及备选参数

- 先闭合设备号、箱号、回路号和服务对象，再比较参数。房间用途相同或位置接近，不足以认定暖通风机与某个电气支路是一一对应关系。
- 动态块多种功率/保护备选同时被提取时，按[CAD证据核验](cad-evidence-verification.md)核当前显示选项；不能挑选恰好一致的值判通过。
- 额定设备功率、计算负荷与回路预留容量分开；电压/相别疑点应追踪直接供电、控制箱或转换设备。平面与系统编号矛盾仅证明图示标识冲突，不直接认定现场接线错误。
